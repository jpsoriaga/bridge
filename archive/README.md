# Archive

`prototype/` holds an earlier pass that jumped ahead of Phase 1: a Fastify server, pairing tokens, file writes with undo, an allowlisted command runner, and the UI and docs that went with them. It was moved out of `apps/` and `packages/` so that Phase 1 matches its spec (minimal preload, chatgpt.com-only permissions).

None of it is built, linted or type-checked. Use it as reference when doing Phases 2, 4 and 7, then delete this folder.
